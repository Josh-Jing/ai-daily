TOPAS: Workflow-Aware Prefix-State Scheduling for Multi-Agent LLM Serving
论文链接: https://arxiv.org/abs/2608.25523
发布时间: 2026-08-26
类别: cs.CL 计算与语言
论文总结: 多智能体 LLM 服务中，前缀缓存带来根本性权衡：保留 agent 长系统提示的 KV cache 可加速后续调用，却挤占并发批处理的显存；现有调度器往往只顾眼前前缀局部性或整体工作流进度。TOPAS 联合决策保留哪些 agent 前缀与调度哪些请求，按任务最长剩余服务路径的预期缩短与下游前缀复用收益对候选状态打分，并计入前缀迁移与抢占成本，辅以任务级老化机制防止饿死。基于 SGLang 实现，在合成 DAG 与 MetaGPT 工作流上平均/p99 任务完成时间最高降低 39.8%/49.4%。
亮点: 把前缀保留与请求调度合并为单一决策问题，多智能体工作流的任务级 JCT 显著下降。

二、KV Cache 复用相关学术论文
Archer: Adaptive Reuse of Cached Hidden States for Efficient Rollback in Diffusion Language Models
论文链接: https://arxiv.org/abs/2608.08086
发布时间: 2026-08-08
类别: cs.CL 计算与语言
代码: https://github.com/Hxnng/Archer
论文总结: 扩散语言模型允许回滚修正早期预测，但每次去噪更新都会改变全局上下文，迫使 prompt 与响应状态全部重算，推理代价高昂。Archer 提出免训练的非对称 KV 缓存：可变响应状态与当前假设保持同步，prompt 的 K/V 则在有界状态邻域内复用——prompt token 身份固定，有界复用可摊销重复计算，还能延迟试探 token 的反馈，给回滚留出更多纠错机会。论文刻画了复用的误差上界与保真刷新条件。实验取得 33.63% 最佳平均性能与 2.57 倍平均加速，Pass@1 最高提升 3.05 分。
亮点: 首个面向可回滚扩散语言模型的 KV 复用方案，把缓存不可变历史的假设改造成有界复用边界。

类别: cs.AR 体系结构
论文总结: 混合 Transformer-Mamba LLM 提升了长上下文效率，但其异构计算与通信模式给硬件加速带来挑战；芯粒（chiplet）架构可集成专用计算与存储单元，然而静态架构配置与动态运行时策略构成的设计空间过于庞大，难以穷举探索。HYDRA 提出面向混合 LLM 服务的异构芯粒设计空间探索框架，联合探索芯粒组合、摆放、片间带宽供给、动态批处理与运行时调度，并集成通信感知摆放与快速马尔可夫性能估计器以高效捕捉多租户动态。平均吞吐达基线 1.55 倍、首 token 时间降低 43.7%，吞吐最高提升 2.3 倍。
亮点: 用架构与运行时策略的联合探索取代穷举，为混合架构 LLM 的芯粒化部署给出系统化路径。

五、Vibe Coding 的 Nice Practice
实践: 用 Archify 让 Agent 一句话生成交互式架构图，把读懂代码库变成分钟级工作
问题描述: 接手陌生代码库或向团队讲解系统时，手动画架构图费时且难维护，代码一更新图就过期；Mermaid 等文本生图工具画复杂系统时布局混乱、箭头乱飞，仍需大量手工调整，跨团队对齐往往要开四五个 follow-up 会议。
具体做法: 在 Claude Code、Codex、Cursor 等编程 Agent 中安装开源 Skill Archify（https://github.com/tt-a1i/archify），一句"分析这个代码仓库，并生成一张高层运行时架构图"即可让 Agent 理解代码、生成结构化 JSON IR 并渲染为独立 HTML 架构图，支持搜索节点、查看模块上下游、追踪两节点间调用路径；对结果不满意继续用自然语言迭代，如"加入 Redis""把认证模块移到左边""突出缓存失效后的回退路径"。可输出架构图、工作流图、时序图、数据流图与生命周期图五类图，并导出 PNG/SVG 用于文档与评审，图随代码演进持续再生成，不再过期。
来源链接: https://github.com/tt-a1i/archify
