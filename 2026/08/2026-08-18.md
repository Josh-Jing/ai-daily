论文总结: LLM 强化学习后训练常把 RLVR、RLHF 与 agentic 等异构 rollout 混在同一个异步推理服务里，前缀感知路由虽能提升缓存复用，却管不住各类会话对 KV 缓存容量的争抢。论文提出路由层准入策略 MISA-T，融合自适应会话准入、负载感知的 KV 容量分配与驻留时间感知核算，在不扭曲训练器指定负载配比的前提下协调竞争。在 Step3.7 与 Qwen3.6-35B-A3B 上 rollout 吞吐较调优后的缓存感知 vLLM Router 分别提升 53.3% 与 43.6%，50 轮对齐实验中迭代时间缩短 22.8%。

二、KV Cache 复用相关学术论文

Neural Introspection Gating for Adaptive KV-Cache Reuse in Vision-Language-Action Models
论文链接: https://arxiv.org/abs/2608.10824
发布时间: 2026-08-11
类别: cs.RO
论文总结: 视觉-语言-动作（VLA）模型在实时控制中要为相邻帧间几乎不变的视觉 token 反复重算 KV 表示，开销巨大。已有工作 VLA-Cache 对视觉静止区域复用 KV 状态，但其策略只依赖观测空间启发式，不考虑模型自身的不确定性，画面剧变时仍盲目复用导致可靠性下降。论文提出 Gated VLA-Cache：免训练地监控解码时 top-2 动作 token 的 logit 间隔这一零成本置信信号，间隔低于阈值即判定缓存失效并触发全量重算。在四个 LIBERO 套件上基于 OpenVLA 与 OpenVLA-OFT 验证，LibERO-Goal/Long 上可完全找回盲复用损失的精度，同时保留约 80% 的计算节省。
亮点: 用模型自身的 logit 置信间隔当"缓存失效探测器"，为 VLA 推理的 KV 复用补上可靠性闸门。

三、推理 Infra 相关学术论文

Beyond Capacity: Scalable MoE LLM Inference via High-Bandwidth Flash with Direct GPU and HBM Paths
论文链接: https://arxiv.org/abs/2608.14333
发布时间: 2026-08-14
类别: cs.AR
论文总结: MoE 模型迅速膨胀的专家权重让 HBM 容量与成本不堪重负，高带宽闪存（HBF）容量大得多，但传统设计只经 HBM 中转送权重，直连 GPU 的通路被闲置。论文提出双路并行的 HBF 组织：直连路径从 HBF 直达 GPU，中继路径经 HBM 基片转 GPU，整个专家粒度分配到其中一路并发传输，不复制权重也不引入共享中继瓶颈；再靠提前专家判定让 HBF 读取延迟与前序计算重叠，并对不可变专家权重与可变 KV cache 分流管理。事件驱动模拟显示，相对全部经 HBM 中转的设计，代表性负载下吞吐提升 1.94 倍、端到端加速 1.90 倍。
亮点: 把"专家权重走哪条路"变成显式路由问题，GPU-HBF 直连与 HBM 中继双路并发榨出近两倍吞吐。

五、Vibe coding 最佳实践

实践：用 A/B 对照实验调优 Agent 系统提示词，别凭感觉改 prompt
来源: https://code.visualstudio.com/blogs/2026/07/06/optimizing-vscode-coding-harness-model-providers
问题描述: 编码 Agent 常在动手前过度探索——反复搜索、重读文件、比较相邻路径才做一次有效编辑。按 token 计费后，Agent 每一次"闲逛"都是真金白银的成本，还会拖慢交付。大多数人改系统提示词靠直觉，改完既不知道是否真的更好，也不知道代价是什么。
具体做法: 学 VS Code 与 OpenAI 联合调优 GPT-5.5 的做法：先把观察到的行为问题收敛成单一可检验假设（"少探索、早验证能否又快又省"），离线评估筛出候选 prompt 变体后，再上线上流量做三组 25/25/25 对照实验，用真实用户流量对比工具调用次数、尾端 token 消耗与编辑耗时等指标，胜出变体才全量发布。核心是把 prompt 当产品而非咒语：任何修改都要先立假设、再做离线评估、最后用线上实验验证后才上线。
