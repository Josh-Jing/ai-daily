KVBoost: Chunk-Level Key-Value Cache Reuse with Deviation-Guided Recomputation for Efficient Large Language Model Inference
论文链接: https://arxiv.org/abs/2608.21362
发布时间: 2026-05-21（2026 年 8 月公开）
类别: cs.AI / cs.DC
论文总结: 前缀缓存只有当共享内容位于提示词头部时才能复用 KV，片段出现在任意位置时便失效。KVBoost 提出与位置无关的块级 KV 复用：双哈希键分离位置身份与内容身份，支持精确与近似匹配；针对独立缓存块带来的注意力边界误差，提供边界区域选择性重编码与探测后重算高偏差 token 两种修复策略，并配合 int8/int4 非对称量化、自适应分块与固定内存预算下的重要性加权逐出。在 Qwen2.5-3B 的千条缺陷定位样本上，TTFT 降低 4.49 倍（142.4ms 对 639.1ms），比前缀缓存再快 16%，准确率无损。
亮点: 双哈希键让 KV 复用摆脱前缀位置限制，共享内容出现在任意位置都能命中。

实践: 用设计文档做 Agent 会话之间的记忆载体
来源: https://www.aitntnews.com/newDetail.html?newId=28603
问题描述: 每个 Agent 会话的上下文窗口有限，从设计进入开发往往开启新会话，前一会话的思考过程、决策依据与技术方案带不过去；没有文档衔接，下一个会话等于从零开始，既要重复交代来龙去脉，又容易偏离已定方案。
