1. Multi-Turn LLM Conversations under the Least-Recently-Used Policy: Mean-Field Asymptotics and Hit Ratio Approximation
论文链接: https://arxiv.org/abs/2609.02027
发布时间: 2026-09-01
类别: cs.PF 性能（math.PR 概率论）
论文总结: 现代 LLM 服务的主要负载已从单轮调用转向多轮对话，KV cache 命中率（从 HBM 中直接命中已缓存前缀的平均比例）成为决定系统性能的关键指标。作者将系统建模为 LRU 驱逐策略下的多轮对话模型，通过平均场渐近框架证明：当对话到达率与缓存容量成比例增长时，命中率收敛到一个闭式极限。基于该极限刻画，论文进一步提出实用的命中率估计器，并在 Ascend NPU 上基于 Qwen3-8B 的真实 LLM 服务实验验证了估计精度。该工作为多轮 LLM 服务系统提供了理论分析基础与缓存容量供给的实用指导。
亮点: 用平均场理论为多轮对话 KV cache 的 LRU 命中率给出闭式渐近解，可直接指导 HBM 容量规划。

1. DASC: Decay-Aware State Compression for Hybrid Linear-Attention Serving
论文链接: https://arxiv.org/abs/2608.30386
发布时间: 2026-08-31
类别: cs.LG 机器学习（cs.AI 人工智能）
论文总结: 混合线性注意力架构虽大幅减缓 KV cache 增长，但其原地递归状态更新使前缀复用变得复杂：需要保存状态检查点，全量存储又加剧内存压力、引发频繁驱逐与重复 prefill。作者分析 GDN 与 KDA 的衰减结构，发现不同头和通道以显著不同的时间尺度保留前缀信息（定义为保留视界），据此提出 DASC：从模型权重推导保留视界，选取长视界状态单元并打包为紧凑检查点布局，再跨 TP rank 均衡分布。在 Kimi-Linear 上，保守配置可将 KDA 状态检查点压缩 2.63 倍，同等内存预算下平均 TTFT 降低 42.6%、输入吞吐提升 68.4%，方法同样适用于 Qwen 的 GDN 架构。
亮点: 利用线性注意力状态固有的衰减异质性压缩前缀检查点，以近乎无损的方式换回近七成的输入吞吐提升。

五、Vibe Coding 的 Nice Practice
1. 用 PRD 和线框图先明确意图，再分步提示
问题描述: vibe coding 时直接丢一句“帮我做个项目管理应用”，AI 只能靠猜测补全大量未言明的需求，产出物逻辑混乱、隐藏错误多，后续返工和调试成本远超省下的时间。
具体做法: 在提示之前先写一页纸 PRD，讲清楚三件事：要构建什么、给谁用、如何运作（数据从哪来、角色权限如何划分），可以先让 AI 起草再人工校对；随后用 Figma、Whimsical 或 Miro 画出关键界面线框图与用户流转路径，多数 vibe coding 工具支持直接导入截图或草图让 AI 更准确理解布局。进入编码阶段后把构建拆成小的目标驱动步骤，例如先“建立含客户、状态、截止日期字段的数据库”，再“创建按状态过滤的看板视图”，每步让 AI 理解结构后再推进；同时开启版本控制，每次大的 AI 修改都留存检查点，新提示破坏功能时可即时回滚。
