二、KV Cache 复用相关学术论文
1. A Universal Context-Reuse Layer for Cross-Model KV Sharing
论文链接: https://arxiv.org/abs/2608.30963
发布时间: 2026-08-31
类别: cs.LG 机器学习
论文总结: 现有 KV cache 复用机制要求缓存的生产者与消费者是同一个模型。本文研究跨模型 KV 共享，将源模型产生的 KV 状态翻译为异构目标模型可消费的表示，可跨越模型规模、架构、注意力配置、分词器与模型家族。实验显示，Qwen2.5-7B 到 1.5B 的翻译使 LongBench2 准确率从 27.59% 升至 34.48%；跨家族场景下目标侧 prefill 成本最多降低 67.05%；Llama3.1-70B 到 Qwen2.5-7B 的时延从 899ms 降至 138ms。
亮点: 让 KV 状态成为可跨模型迁移的计算表示，提出 context mobility 抽象以消除异构多模型工作流的冗余 prefill。

三、推理 Infra 相关学术论文
1. VPP: Virtual Pipeline Parallelism for Efficient Chunked Prefill in Long-Context LLM Inference
论文链接: https://arxiv.org/abs/2608.26523
发布时间: 2026-08-27
类别: cs.DC 分布式与并行计算
论文总结: 长上下文推理中，分块 prefill 流水线并行因后序 chunk 前缀更长、注意力开销更高而产生流水线气泡，动态调整 chunk 尺寸又会引入额外调度开销。VPP 保持 chunk 大小固定，转而通过虚拟阶段重排流水线布局，以 V 形遍历让每个 chunk 的重负载中间阶段与相邻 chunk 的轻负载首尾阶段重叠，并辅以异步通信与流水线打包。该系统基于 vLLM-Ascend 实现，在 16 卡昇腾 910C 上评估，长序列吞吐较动态分块方案最高提升 13.1%，512K token 的 DeepSeek-V3.1 prefill 流水线气泡率从 6.4% 降至 0.1%。
亮点: 用虚拟阶段重排取代动态调块，几乎消除长序列 prefill 的流水线气泡。

五、Vibe Coding 的 Nice Practice
1. 用 plan-review-fix 循环逃离 vibe coding 死亡循环
问题描述: vibe coding 时需求反复变化，代码在数据层、控制层、视图层之间积累不一致，最终陷入死亡循环：agent 声称修好了 bug 却始终没修好，无论怎么提示都无济于事，只能推倒重来。
具体做法: 在 markdown 里而非代码里迭代计划。先与规划 agent 讨论出端到端方案，再交给一个独立的 plan-reviewer agent 以全新视角审查逻辑漏洞、过度设计与双方的共同盲点，把反馈整合回计划，直到人、规划 agent、审查 agent 三方满意。实施时开启全新会话重置上下文（避免 context rot 导致输出质量下降），实施完成后再由 code-reviewer agent 重点检查错误处理、测试覆盖与安全三个高风险面。
来源链接: https://www.producttalk.org/vibe-coding-best-practices/
