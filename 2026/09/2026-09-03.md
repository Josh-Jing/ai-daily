1. OUTLETS: Output-Length Prediction from Speculative Decoding Backbones
论文链接: https://arxiv.org/abs/2609.01068
发布时间: 2026-09-01
类别: cs.CL 计算与语言（已被 EMNLP 2026 接收）
论文总结: LLM 服务的输出长度呈重尾分布，给资源供给与集群调度带来挑战；现有预测方法或依赖外部代理模型引入额外时延，或仅浅层探测模型内部状态。作者发现投机解码框架（如 EAGLE-3）中草稿解码器的隐含表示蕴含可预测生成长度的信号，据此提出 OUTLETS，在投机骨干上仅添加一个轻量回归头即实现轨迹感知的长度预测，MAE 优于已有方法。在饱和的分离式服务中，该预测让标准调度策略优先处理短请求并更均衡地分配解码实例，短请求 P99 时延降低 34.8%。
亮点: 把投机解码的草稿模型零成本复用为长度预测器，几乎不增加推理开销即显著改善调度。
二、KV Cache 复用相关学术论文
1. CacheBridge: Efficient Cross-Model KV Cache Transfer
论文链接: https://arxiv.org/abs/2609.00891
发布时间: 2026-09-01
类别: cs.AI 人工智能
论文总结: 多模型系统共享上下文时，接收模型需重新 prefill 共享前缀，因为 KV cache 与模型绑定。已有闭式跨模型 KV 映射把每个目标 KV 头映射自全部源 KV 头，对架构差异敏感且存储与计算开销随层数增长。CacheBridge 将每个目标头限定为匹配的单个源头，按因果注意力敏感度加权重建误差，并用融合 GPU 内核构造加权充分统计量。在 Qwen3 14B 到 32B 方向上，映射存储减少 8 倍、应用加速最高 3 倍，500 条序列的构造时间从 92.63 秒降至 8.63 秒，并恢复了先前方法在两个 Ministral 3 迁移方向上损失的精度。
亮点: 头对头的闭式仿射映射让 KV cache 可跨模型高效迁移，存储与构造开销下降一个数量级。
三、推理 Infra 相关学术论文
1. AInfer-PD: Communication-Safe In-Place Prefill-Decode Multiplexing for Distributed MoE Rollouts
论文链接: https://arxiv.org/abs/2609.00993
发布时间: 2026-09-01
类别: cs.DC 分布式与并行计算
论文总结: 大规模智能体 RL 中，rollout 推理常占主要墙钟时间；异步轨迹使 prefill 与 decode 在共享加速器上持续共存、相互干扰。P/D 分离需要独立设备池与 KV 传输，现有原地复用又缺少面向大规模 MoE 的通信隔离：P 与 D 可能以不一致的跨 rank 顺序发出交叉集合通信，DeepEP 双路径还共享可变协议状态。AInfer-PD 协调跨 rank 的 P/D 通信顺序并为 DeepEP 提供独立路径状态，同时保留共享权重与 KV 存储。实测单节点 rollout 完成时间较 SGLang 降低 24.8% 至 32.9%，双节点降低 18.3% 至 31.8%。
亮点: 首次让 P/D 原地复用在分布式 MoE 上通信安全，无需分池即可显著加速 RL rollout。

五、Vibe Coding 的 Nice Practice
1. 为 LLM 选择更严格的编程语言与类型系统
问题描述: vibe coding 时 LLM 上下文有限，用动态类型等宽松语言写代码，错误往往要到运行时才暴露，LLM 在长会话中不断累积小错甚至退化为低质量输出，人也难以及时发现和定位。
具体做法: 把编译器当作 LLM 的免费代码审查员。优先选用 Rust、Haskell 这类"编译即正确"的强类型语言，让类型系统和借用检查在编译期拦截空指针、越界等错误，把 LLM 的有限上下文留给真正的业务逻辑；在多 agent 工作流中先让高层 agent 产出抽象计划，再把机器码生成这类精确繁琐的低层转换交给编译器而非 LLM，各司其职。
